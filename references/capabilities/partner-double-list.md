# 用优缺点双表检查注意力偏向

## R — Reading

> 第一张表上列的每一项得十分,第二张表上列的则扣十分,看看你的亲密关系是正分还是负分呢?

来源：第一章后的练习，PDF页序37（引文删除排版空格）。

## I — Interpretation

近期的不满可能占据全部注意力。
双表让初识时的优点、新发现的优点和当前缺点同时出现。
原书给每项相同的十分，只是在数列出的条目。
因此分数可以帮助发现清单的分布，却不能衡量严重程度。
重大伤害不能被多条普通优点抵消。
这张卡完成反思清单，不对关系好坏或去留评分。

## A1 — Application Example

**原书未提供可复算的个案清单**；PDF37仅说明有些读者做练习后发现自己忽略优点，没有给出其逐项记录与得分。

**明确标记的合成演练。**优点：愿意倾听、认真工作、记得纪念日，共3项；缺点：常迟到、家务安排不清，共2项。按原书规则，S=10×3−10×2=10分。只表示本次正面条目多一项，不能推出关系健康或应该留下。迟到与家务问题仍各须处理。

## A2 — Future Trigger

- 最近只看得到不满：“我忘记当初喜欢他什么 / only see flaws”。
- 想把双方看法写清楚：“帮我列伴侣优缺点 / partner strengths and weaknesses”。
- 读到书中计分练习想复算：“三个优点两个缺点怎么算 / double list score”。

与 shadow-self-reflection 区分：本卡核对注意力与清单；后者探索一项强烈评判中的自我感受。不用于关系健康量表、安全判断或是否离开的决策。

## E — Execution

输入：本人确认的初识优点、新发现优点、当前缺点（文本列表，可空），以及希望保留的重要问题。缺清单先询问，不虚构伴侣特质。只提供一面时先邀请补另一面；拒绝或无法回忆可保留空项并注明。

1. 建两张表：优点含初识与新发现；缺点含目前观察。完成：每条都来自本人，重复意思核对后合并。重复处理为编排约定，不能随意增删以改变分数。
2. 确认条目数 n+、n−（非负整数）。按 S=10n+−10n− 顺序计算，无单位、无需舍入。完成：展示两项计数和算式。
3. 解释为“本次列出的正面/负面条目数量差”，检查遗漏或注意变化。完成：不从正负或零分推断关系质量。
4. 另列严重性、尚需核实及实际待处理问题。完成：不将伤害抵分，不据得分决定去留。

输出：优点表（初识/新增）｜缺点表｜计数｜公式及分数｜注意力观察｜重要问题｜缺失信息。本人只想讨论现实伤害时停止计分，不能要求先写优点。

## B — Boundary

原书提示人们可能忘记吸引之处而专注缺点，但未提供验证量表，也未给条目严重性权重。等权十分只反映清单数量。清单不能取消行为责任；“优点多”也不代表安全、健康或应当留下。去重、缺失记录、严重性单列和禁止去留判断，是本次保守编排。不要为追求正分引导用户加优点或删缺点。
