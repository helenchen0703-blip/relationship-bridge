# 用图像看见为获得爱而缩减自己

## R — Reading

> 你可以用口头表达,或在心里对伴侣说你们不需要再继续这种不实的亲密关系,你会做出对两个人都好的选择。

来源：“依附——束缚之索”，PDF页序189（引文删除排版空格）；定义与图像示例见186–188。

## I — Interpretation

当怕失去爱使人藏起兴趣或个性时，图像能帮助表达这种感受。
先呈现现在如何被绑住，再找出自己舍弃的部分。
可以留意熟悉的感觉，但不必推定童年原因。
用语言表达想取回自己的意向，再描绘松绑与希望的相处。
最后一幅图是愿望，不能证明现实关系已经改变。
图里仍有冲突，也是可记录的信息。
目标是更清楚地说出自己，不是画出“正确关系”。

## A1 — Application Example

**作者自述，PDF186–187。**作者在孕期妻子经过时突然想深夜打扫，随后联想到小时候以整理环境换取母亲开心和接纳。他把这看作为得到爱而收起自己的一例；这是作者解释，不是对所有家务行为的诊断。

**书中转述图像，PDF187–188。**一位女性案主把自己画成被捕兽器夹住，另一端锁在父亲身上。书中此处未报告图像练习后的实际结果。

**合成演练。**当前图：画笔被绳索连到伴侣情绪；舍弃的是画画。希望图：两人有联结，也各有活动空间。已表达“我想保留画画”，尚未验证现实可行性，仍害怕被嫌弃。

## A2 — Future Trigger

- 害怕不被爱而放弃兴趣：“我不敢做自己 / afraid to be myself”。
- 总按伴侣情绪调整一切：“像被绳子绑住 / attachment image”。
- 难用语言描述空间需求：“我想画出有联结又自由的样子 / room to be myself”。

与 willing-giving 区分：后者检查具体付出的内疚动机；本卡处理被缩减的自我形象，只在本人愿意用图像时调用。寻求依恋类型诊断、预测对方反应时不调用。

## E — Execution

输入：本人描述的关系场景、为了避免排斥而放下的部分（若知道）、是否愿意想象或画画。图像可用文字、纸笔或黏土描述；无须上传。缺场景先问，不代造童年记忆。

1. 描绘当前相处中的束缚。完成：至少描述自己、对方和联结方式；图像属于感受表达。
2. 记录身体/情绪感觉、熟悉与否、放弃的部分。完成：已知与未知分开；不要求找出家庭根源。
3. 自愿表达希望取回自己的意向，可只在心里说。完成：一句本人认可的意向；不愿则停。
4. 描绘松绑过程，再画希望的相处。完成：两幅描述可区分过程与愿景，不要求断绝关系。
5. 记录剩余冲突和愿意面对的现实问题。本次先做一轮；是否继续由本人选。完成：保留未解决部分，未发生的变化标“待观察”。

输出：当前图｜感觉｜缩减部分｜意向｜松绑图｜希望图｜未解决事项。越来越难受、不愿继续或无图像时可停，不强求重画。

## B — Boundary

原书提示松绑可能引起不愉快的连锁反应，且双方步调可能不同。本卡不把图像当诊断、未来预言、实际协商或改变对方的工具；不采纳“必定只需内在改变便无需离开”的保证。自选停止、限制重画、保留事实责任和区分愿景/实际，是本次编排。存在威胁、实际控制或紧急风险时，不以此替代处理现实事项。
