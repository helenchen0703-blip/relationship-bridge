# 用真诚感谢松动沟通僵局

## R — Reading

> 重要的是,我的心意是诚挚的,而且感谢的话能化解我们之间的僵局。

来源：第二章沟通方法，PDF页序134（引文删除排版空格）；上下文见133–134。

## I — Interpretation

僵局中，人有时只剩下抱怨而忘记自己仍认可的事。
若真心愿意靠近，可以从一件具体、真实的事表达感谢。
感谢不用夸大，也不要求抹去尚未解决的问题。
说完留意对方有没有意愿交流。
对方是否愿意回应无法由一句话保证。
完成的是自己的诚实表达，而不是“成功让对方合作”。

## A1 — Application Example

**作者自述兼话语演示，PDF134。**作者回忆几次自己生气受伤、不愿主动求和，仍选择说感谢的话；书中称其帮助化解僵局，并演示感谢对方努力理解自己的说法。该段未交代每次争执细节或逐次结果，不能推成固定效果。

**合成演练。**输入：家务问题未解决，但昨天伴侣认真听我讲困难。草稿：“谢谢你昨天认真听我讲困难，我觉得被重视。”家务分工仍须另谈，对方是否愿意接着聊未知。

## A2 — Future Trigger

- 吵后仍认可具体付出：“我想说谢谢，但开不了口 / sincere appreciation”。
- 谈话僵住，想用真实认可开场：“他昨天认真听了我 / gratitude after conflict”。
- 想表达对方的重要性：“有件事我确实很感激 / genuine thanks”。

与 loving-action-experiment 区分：本卡输出感谢话语；后者通过想象与一个自主行动观察新回应。若诉求是让对方欠人情、必须和好，不使用本卡达成该目的。

## E — Execution

输入：一件本人确实感激的事及发生情境、真实感受、是否愿意表达。缺具体依据时询问；找不到真实感谢点不代造。

1. 检查意图是否是自愿表达认可，而非交换服从。完成：本人选择愿意或暂不愿意；后者可停。
2. 选一件有依据的事，写对自己的意义。完成：事件与感受不夸大，未把伤害改写成恩惠。
3. 生成简短感谢句，不附带逼迫或隐含账单。完成：仅含本人认可的内容，未解决事项另记。
4. 若本人决定使用，观察对方回应，再判断是否适合继续谈。完成：实际/待发生分开；对方不想谈即停，不反复感谢施压。

输出：感谢依据｜感谢草稿｜真实感受｜未解决事项｜对方回应或未知｜下一步意愿。没有真实依据也可输出“暂不表达”。

## B — Boundary

原书提醒感谢可能随相处减少，也强调诚挚；不真诚的话不满足本卡契约。不要求感谢伤害、放弃异议或承担对方全部感受。原书关于迅速化解僵局的陈述是作者经验；不保证效果。缺项可停、保留事实责任与不以回应换取合作是本次编排。需要认错时转 specific-apology，而不是用赞美绕过责任。
