# 打开两难之外的选择

## R — 原文

> 要愿意接受两个选择中的任何一个,或是两个都不选。

《亲密关系》全新修订版，PDF页序166；两难示例和讨论见163–167、212。

## I — 自述

两难往往把两个损失明显的选项当作全部可能。
先写每个选项想保护什么、怕失去什么。
允许考虑任一个，也允许暂时不选，松开必须立即二选一的假设。
再探索组合、条件改变或第三个可能。
相关人的利益需要询问，不能凭想象宣布人人满意。
输出额外可检验选项，最终决定仍归本人。

## A1 — 应用示例

原书案例描述（PDF163）：一人想离开稳定办公室工作做艺术，又担心经费保障。原书展示两难结构，此例未给最终实作结果。
合成演练：每周末探访伴侣父母或彻底断交，分别怕失去休息和联结。增加隔周探访、缩短时长两种待讨论可能；不判断父母必定接受。下一步先与伴侣商谈时间和想保护的关系，是否实行未知。

## A2 — 触发与相邻区分

- 觉得只能忍耐或断开：“只有这两条路 / only two options”。
- 两边都怕失去：“怎么选都亏 / dilemma”。
- 征求更宽的方案：“有没有第三选择 / third option”。

本卡扩展选项；values-and-choice辨认某个行动背后的动机和价值。若已确定行动只需表达，不必重做选项探索；不替用户决定关系去留。

## E — 执行

输入：两个选项（文本）、各自担心的损失、已知约束与期限、相关人；缺两个选项先问，约束未知要显式记录，不能视为不存在。

1. 列A/B的“保护什么、失去什么、依据是什么”；完成标准是能说明两难而非泛称难受。
2. 问本人是否愿暂时考虑A、B或暂不选，不等于承诺实施。若不愿，记录不愿与理由；不强迫放下，也不假报释然。
3. 探索组合、缩小规模、调整时段或第三方案；每项写改变了哪条假设。未找到就写尚无新增选项，不编造可行性。
4. 逐项核对现实约束及相关人的利益与意愿；未经对方确认只叫提案。写一个询问、调查或讨论步骤及需补信息。

输出：A/B对照｜开放意愿｜新增方案/尚无｜约束和他人意愿未知项｜下一项验证动作。形成选项地图与可验证下一步即完成，不要求选定、平静或双赢。

## B — 边界

原书警告给两难者不断提答案可能使帮助者转为责怪；本卡不争辩“你其实可以”。作者以心中答案与对所有人最好为方向，本次不把平静当作最优证据，不保证一定有可行第三路。实际期限、既有义务及损害不能因“都不选”而被忽略。
