# 识别控制与报复，停止自己使用的武器

## R — 原文

> 你必须了解自己在报复时用了什么作为武器,并且让伴侣知道。

《亲密关系》全新修订版，PDF页序124；表达方式见64–65、86–90，报复见123–124。

## I — 自述

把模糊的“沟通不好”缩成自己的具体言行。
可检查公开攻击、刻意抽离、表面无事但借讽刺伤人三种方式。
沉默本身不证明攻击，需要当事人意图或情境依据。
若自己承认想让对方内疚、痛苦或受罚，再检查报复成分。
找到一件自己能停止的行为，并把隐藏感受改为直接表达。
不以解释动机免除行为责任，也不诊断对方。

## A1 — 应用示例

原书作者自述（PDF87–88）：度假时双方持续互相贬低，在雨中山路大吼且加速；作者后来认为自己用言语伤人。此例展示升级风险，不复现危险行为。
合成演练：输入“我反复叫他大忙人，想让他内疚”。输出：有自述意图支持被动攻击；停止“大忙人”讽刺；改为“我有些失落，想谈谈相处时间”。是否实施、对方反应未知。

## A2 — 触发与相邻区分

- 嘴上说没事却讽刺：“我想刺他一下 / sarcasm”。
- 承认用冷落惩罚：“我要他难受 / retaliation”。
- 想查自己的控制：“我是不是在逼他内疚 / make them feel guilty”。

本卡先识别和停止具体行为；eight-question-dialogue整理整场对话；specific-apology处理已确认做错部分的道歉。仅问对方为何沉默，不据此激活动机诊断。

## E — 执行

输入：自己的原话/动作（文本）、发生情境、本人意图（可未知）、是否愿意停止；缺少行为先询问，不能仅凭愤怒定性。

1. 写可观察动作与本人所述意图，分开事实和推断；完成标准是每个判断有依据。
2. 对照攻击、刻意抽离、被动攻击，允许未匹配。问是否想让对方受伤、歉疚，或因其痛苦高兴；未知不判报复。
3. 选自己使用的一件“武器”，记录可能伤害；询问自愿停止意愿，不愿则只交付观察，不替其保证。
4. 愿意时写停止动作与一句直接感受表达；如对方愿听可说明自己的具体行为，并询问其实际影响。对方感受未经报告留未知。

输出：行为｜证据与意图｜匹配类型/不确定｜拟停止动作｜替代句｜未确认影响。形成可由本人执行的一项改变即完成，不报告已经改变。

## B — 边界

原书警告把报复说成“让他知道我的感受”是在合理化伤害。本次不采用仅凭受伤感觉就断定对方报复，也不将一切沉默当暴力；休息、表达困难需另看情境。伤害事实与责任保留，不能说双方都无错。遇威胁或危险先停止互动，勿继续用语言练习化解危险。
