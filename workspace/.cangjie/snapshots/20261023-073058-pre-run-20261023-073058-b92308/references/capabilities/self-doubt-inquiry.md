# 把自我否定转成观察与提问

## R — 原文

> 不要和这个“把关者”战斗,因为这样只会让它变得更强大。

来源：Christopher Moon《亲密关系：通往灵魂的桥梁》，中文2012年版，PDF文件页序209（非纸书页码）；引文标点、空白规范化。

## I — 自述

先逐字听清自己说的否定话。
辨认其引起的感觉，不急着把它消灭。
过去发生的事与未来必然失败是两类陈述。
把自我判决改写成可以调查的问题。
现实资料缺口单列，不能以积极想法填补。
本卡只组织观察，不鉴别风险合理性。

## A1 — 应用示例

原书亲历自述（203–205）：作者主持研讨会时反复预测听众会离开，虽有超过半数参与者感谢他仍把它解释为客套或受骗。作者说自己继续工作，后来体验更多创造力；这是自述，不是方法疗效证明。合成演练：“上次沟通失败，这次一定无效。”已知为上次失败，预测为这次必败；问“这次条件是什么？我希望怎样回应？”对方状态及风险未核，不能判担心不合理。

## A2 — 触发与相邻区分

把上次争吵推成今后必失败；被“我不值得爱”压住；想听清自己的否定而不与之纠缠。信号：“我肯定不行”“注定失败”；self doubt, I cannot, doomed to fail。values-and-choice 处理行动动机；本卡不回答离开是否正确，也不评估对方危险程度。

## E — 执行

必需：本人否定话语、触发情境；感受未知要问或标未知，不推断创伤。
1. 原样记录一句自我判决；完成标准为可辨识语句。
2. 分列已发生事实、未来预测、价值判断；证据不足标待核，不把担忧自动分成“不合理”。
3. 记录本人感觉，允许不愿继续；不逼深挖。
4. 为预测或判断写开放问题，如“缺少哪些信息”“此刻可做什么”；完成标准为问题不预设必成功。
5. 若需判断风险是否合理，明确本卡无此能力，另行核实，不鼓励忽视警讯。
输出：原话、触发、本人感受、事实/预测/判断、开放问题、资料缺口、停止状态。未消除怀疑也可完成。

## B — 边界

原书反例（204–205）：正面反馈也被重新解释为否定。作者局限：将所有怀疑归于小我，并把统计等证据描写成恐惧工具，可能削弱现实核查。本卡不采用该泛化；不判担忧合理与否，不以相信自己取代准备和证据。

本文字段、完成标准、未知标记和停止条件为蒸馏编排，不冒充原书既有程序。
