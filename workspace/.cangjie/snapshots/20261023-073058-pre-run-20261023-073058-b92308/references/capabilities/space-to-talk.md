# 邀请沟通并给对方选择空间

## R — 原文

> 有效的应对方式是让他知道,如果想要谈谈的话,她随时都有空,然后给他很多的个人空间。

来源：Christopher Moon《亲密关系：通往灵魂的桥梁》，中文2012年版，PDF文件页序133（非纸书页码）；引文标点、空白规范化。

## I — 自述

对方此刻不愿说话，可以先承认其选择。
邀请要表达可谈，而不是催促。
发出邀请后停止反复追问。
留空间不能暗藏“我等过了，你就欠我回应”。
真实事务若有期限，另外清楚说明。
对方是否开口由实际回应确认。

## A1 — 应用示例

原书转述咨询情境（133）：妇女抱怨丈夫每逢谈话就离开或看报；作者建议告知愿意倾听，再留空间。作者也记载案主说给过空间仍没回应，因此并未提供可核对的开口时间或成功保证。合成演练：伴侣今天不想谈非紧急周末安排，回复“你今天不想谈，我听到了。愿意谈的时候可以告诉我。”随后停止追问。

## A2 — 触发与相邻区分

对方说今晚不想谈；追问使谈话更退缩；想写一条无催促的邀请。信号：“给点空间”“不想谈”；space, not ready to talk, invitation。愿谈后要梳理内容用 eight-question-dialogue；沉默是否有恶意或关系是否值得继续不是本卡裁决。

## E — 执行

必需：对方已表达/可观察的不愿谈情况、谈话议题、是否紧急及有无现实期限；不清楚期限先问。
1. 如属紧急或不能等的事项，停止本卡，单独处理实际事项。
2. 写承认当下选择及愿意倾听的邀请；完成标准为可拒绝、无内疚施压。
3. 明确自己停止哪种追问；完成标准为一项可观察行为。
4. 有现实期限另述事实及需要商量的时间，不承诺永远等；无回应记未知，不连续发邀请作测试。
输出：适用条件、邀请句、停止的行为、期限（无/待核）、实际回应、后续待办。草稿完成不代表对方已开口。

## B — 边界

原书反例（133）：以蛮力拖兔子的隐喻描述逼问加重退缩；“我给空间了他还不说”暴露隐藏要求。编排边界：不照搬单方必能解决的保证；空间不取消责任、期限与用户的自由选择。

本文字段、完成标准、未知标记和停止条件为蒸馏编排，不冒充原书既有程序。
