# 决策规则速查 — 亲密关系：通往灵魂的桥梁

| 能力 | 一句话规则 |
|---|---|
| 识别期望背后的需求 | 写希望对方做的事→问想获得何种感受→若仍是行动要求则再问→自选是否松开必须由对方满足的要求→观察变化。 |
| 识别控制与报复，停止自己使用的武器 | 记录言行和自己的意图→对照表达方式→检查是否希望对方受伤或歉疚→找出自己使用的武器→自愿停止并表达真实感觉。 |
| 用沟通八问整理冲突 | 我想要什么→有何误会→我表达的真实情绪→是否熟悉→已知来源→如何回应→背后何种感觉→能否以关怀回应；未知保留未知。 |
| 用表达与意象练习观察当下情绪 | 自选一种→承认感觉→按相应原文步骤表达或观察→记录得到的表达和前后自述；不愿或更难受可停。 |
| 看见戏剧三角的角色循环 | 还原一轮互动→标记自己在拯救、责怪或无力间的转换→记录感受→问事实是什么、现在能做什么→选一个不继续扮演角色的动作。 |
| 打开两难之外的选择 | 列两个选项及失去什么→允许接受任一个或都不选→探索组合或第三选项→考虑相关人的利益→确定待验证的下一步。 |
| 辨认家庭惯例，试一次不同回应 | 记录触发和自动回应→对照已知家庭惯例→区分爱家人与沿用旧方法→寻找有创意的新回应→记录实际结果。 |
| 区分自愿付出与内疚驱动的牺牲 | 选一次付出→想象说好/说不各有什么感受→检查赎罪、被接纳与换感激的动机→允许感受内疚而不攻击自己或对方→选择真正愿意的付出和接受。 |
| 用图像看见为获得爱而缩减自己 | 画当前被束缚的相处→记录熟悉感觉与放弃的部分→表达想做自己的意向→画解绑过程及希望的相处→标记仍存冲突，不无限重画。 |
| 把强烈评判转为有边界的自省 | 写受不了的特质及行为依据→尝试寻找自己类似信念/感觉→接纳已确认的部分及不自在→找真实欣赏点→检查变化，未匹配或不愿继续可停。 |
| 承认伴侣间的竞争，转向支持 | 列竞争及扯后腿的具体行为→检查害怕落后什么→回答伴侣、自己、真理是否值得面对羞耻去承认→自愿承认→支持对方的长处。 |
| 用真诚感谢松动沟通僵局 | 检查是否真心想靠近→找一件真实可感谢的事→简明表达→观察对方回应，再决定是否继续谈。 |
| 用优缺点双表检查注意力偏向 | 列初识及新发现优点→另列当前缺点→按每项正负十分计数→观察注意偏向及遗漏→把重要问题另记。 |
| 想象融洽时的自己，试一个善意行动 | 假设此刻相处融洽会怎样→我能做什么并先试一个自主小行动→留意若相爱我会有什么感受→我会如何看待对方→观察真实变化。小行动的范围和不保证回应属于执行编排。 |
| 让发现问题与提出方案相互配合 | 一方提出顾虑→另一方聆听提案→前者检视方案问题→修正→共同查看剩余顾虑和可行性。 |
| 为自己实际做错的部分诚恳道歉 | 找实际错误→检查是否愿承认→清楚说出并诚恳道歉→听对方回应→承担自己后续行为。 |
| 邀请沟通并给对方选择空间 | 表达如果愿谈我在→停止逼问→留真实空间而不暗中考验→观察是否有自愿交流→需要处理现实期限时另行说明。 |
| 把自我否定转成观察与提问 | 听到自我否定内容→记录引起的感受→不忙于服从或争斗→用开放问题检视→把未知的现实信息另记。 |
| 辨认行动驱动力，表达自己的选择 | 选具体行动→参照允许/为做而做及个人/重要对照→写动机、希望保护的价值→保留事实和他人意愿未知→表达自己的决定或下一步。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
